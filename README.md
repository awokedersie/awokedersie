## 💻 Featured Projects

### 📌 Hospital Management System (HMS)
A comprehensive web-based Hospital Management System developed for Alem Ketema Enat Hospital. It securely manages patient records, handles doctor appointments, processes billing, and streamlines staff workflows.

### 📌 DBU Clearance System
A full web-based system automating the student clearance process at Debre Berhan University. Connects multiple departments to digitally manage, approve, and track clearance requests in real-time, reducing manual processing delays.

### 📌 Food Ordering Platform
A dynamic online food ordering platform where users can browse restaurant menus, place orders, and track deliveries. Includes a secure admin panel for managing restaurants, menus, and incoming customer orders.

### 📌 Financial Tracker App
A mobile application built with Kotlin for tracking personal income, expenses, and financial goals. Features visual analytics charts and an intuitive category-based budget management system for Android devices.
